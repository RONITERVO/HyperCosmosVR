## 3. Bilingual Narration & SyncVoice Asset Contract

### 3.1 Deterministic Content-Addressed `externalId` Formula (`scripts/extract-syncvoice.mjs`)

```js
const stableSourceKey = locale === "es-ES" ? sourceKey : `app-${appId}:${sourceKey}`;
const sourceIdentity  = `syncvoice:v1:${locale}:localization-key:${stableSourceKey}`;
const externalId      = `${prefix}-${sha256(sourceIdentity).slice(0, 24)}`;
// Prefixes: es-ES -> "sq-es", en-US -> "sq-en", fi-FI -> "sq-fi"
```

- **Critical Scoping Symmetry Difference:**
  - **`es-ES` IDs are globally deduplicated across all 25 apps:** `stableSourceKey = sourceKey` (attributed in `project.json` to the lowest-numbered app where `sourceKey` first appears). Thus `6,415` per-app source keys collapse into **`6,068` unique `es-ES` `.mp3`/`.json` pairs**, eliminating **`347` duplicate slot instances** across **`265` shared Spanish phrases** (e.g., `"Vía Láctea"`, `"Grupo Local"`, `"Laniakea"`, `"Fondo cósmico de microondas"`, `"Marte"`, `"Europa"`, `"Encélado"`, `"La experiencia consciente"`).
  - **`en-US` and `fi-FI` IDs are app-scoped:** `stableSourceKey = "app-${appId}:${sourceKey}"`, yielding **`6,415` `en-US`** and **`6,415` `fi-FI`** files even when the same Spanish phrase appears in multiple apps (permitting context-specific English/Finnish translations per app!).
- **Locale Voice & Prompt Contract (uniform across all `18,898` entries):**
  - `speaker`: `"narrator"`, `voice`: `"Kore"`, TTS synthesis model: `"gemini-2.5-flash-native-audio-preview-12-2025"`.
  - `direction`:
    - `es-ES`: `"Warm, patient educational narration; clear neutral Spanish, unhurried pacing, and gentle emphasis on key terms."`
    - `en-US`: `"Warm, patient educational narration for a school audience; clear neutral American English, unhurried pacing, and gentle emphasis on key terms."`
    - `fi-FI`: `"Warm, patient educational narration for a school audience; clear neutral Finnish, unhurried pacing, and gentle emphasis on key terms."`

### 3.3 Audio Encoding & `syncvoice-cues-v1` Transcript Contract

- **MP3 Bitstream Profile** (verified across 30 sampled files across `es-ES`, `en-US`, `fi-FI`): **`MPEG-2 Layer III`, `96 kbps`, `24,000 Hz`, `Mono`**.
- **Duration Statistics across the Full Corpus:**
  - `es-ES` (`6,068` files): total `522.23 min` (`31,334.0 s`), min `280 ms`, max `20,200 ms`, mean `5,163.8 ms`.
  - `en-US` (`6,415` files): total `493.61 min` (`29,616.6 s`), min `280 ms`, max `19,680 ms`, mean `4,616.8 ms`.
  - `fi-FI` (`6,415` files): total `520.95 min` (`31,257.2 s`), min `370 ms`, max `19,640 ms`, mean `4,872.5 ms`.
- **Cue JSON Schema (`syncvoice-cues-v1`):**
  ```json
  {
    "version": 1,
    "externalId": "sq-es-00085e58a8e3da011f370fbf",
    "text": "lunas",
    "durationMs": 960,
    "cues": [{ "startMs": 0, "endMs": 75, "startChar": 0, "endChar": 5 }]
  }
  ```
- **Strict Validation Rules (`validate-syncvoice.mjs` & `learning-narration.js`):**
  1. `version === 1`, `externalId` matches filename/catalog, `text` matches manifest `text` verbatim.
  2. `cues` is non-empty, `startMs >= previousStart`, `endMs >= startMs`, `endMs <= durationMs`.
  3. `startChar === previousEndChar` starting at `0`, `endChar > startChar`, final cue `endChar === text.length` (strict contiguous character partition covering the entire UTF-16 JS string; **Note for Rust:** cue indices are JavaScript UTF-16 code units, matching Python/Rust `.encode('utf-16-le')` / char-boundary conversion needed for surrogate-pair glyphs if any — convert UTF-16 indices to UTF-8 byte offsets during `.hcvb` baking!).

### 6.3 Rust Zero-Copy Binary Layout (`universe_catalog.hcvb` + `universe_audio.hcvp`)

All structs use `#[repr(C)] #[derive(Copy, Clone, bytemuck::Pod, bytemuck::Zeroable)]` for instant `include_bytes!` / `mmap` loading into `cosmos_manifest`:

- **Header (`HcvbHeader`, `64 B`):** `magic: [u8; 8]` (`b"HCVRCAT1"`), counts & section offsets (`strings_utf8_offset`, `cues_offset`, `assets_offset`, `experiences_offset`, `zones_offset`, `features_offset`, `color_lut_offset`, `music_notes_offset`), plus CRC32 / Blake3 integrity digest of `universe_audio.hcvp`.
- **Packed Records:**
  - `StrSlice { byte_off: u32, byte_len: u32 }` (interned deduplicated UTF-8 strings)
  - `CueRecord { start_ms: u32, end_ms: u32, start_byte: u16, end_byte: u16, start_grapheme: u16, end_grapheme: u16 }` — **Important:** Convert `syncvoice-cues-v1` UTF-16 `startChar`/`endChar` code-unit offsets to exact **UTF-8 byte offsets and Unicode scalar indices** during the bake step so GPU MSDF glyph arrays index cleanly in `O(1)` without UTF-16 re-encoding at runtime!
  - `AudioAssetRecord { mp3_offset: u64, mp3_len: u32, duration_ms: u32, cue_start: u32, cue_count: u32, text: StrSlice, locale: u8, _pad: [u8; 3] }` (`18,898` records, `36 B` each = `680 KiB`)
  - `NarrationPhraseTriple { asset_es: u32, asset_en: u32, asset_fi: u32 }` (`12 B` linking any label/fact directly to all 3 locales in `audioAssets[]`)
  - `ZoneRecord` & `FeatureRecord` storing normalized ranges `[p0, p1]`, RGB color, packed `ZoneSound { base_hz: f32, filter_hz: f32, noise: f32, pulse: f32, wave_kind: u8, pulse_mode: u8, scene_idx: i16 }` driving **`fundsp`** procedural synth graphs directly, plus `NarrationPhraseTriple` handles for `name`, `evidence_class`, `metric_narration`, and `macro_fact` (`zone.fact`).
- **Streaming Audio Decode in `cosmos_audio`:** Given an `AudioAssetRecord`, open a `std::io::Cursor<&[u8]>` over `&hcvp_mmap[mp3_offset..mp3_offset + mp3_len]` with `symphonia` (`Mp3Reader`), decode 24 kHz mono PCM to `f32`, feed through `ssstretch` at active rate `[1.0..3.0]` (bypass stretch completely at `1.0×` for bit-exact zero-artifact latency), apply `hrtf` binaural spatialization (`70%` spatial + `30%` head-locked speech clarity mix), and duck ambient `fundsp` zone drone gain by `-9 dB` during active playback.
