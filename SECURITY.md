# Security Policy

## Supported Versions

`HyperCosmosVR` is currently on active `0.1.x` pre-1.0 development on the `main` branch.

| Version / Branch | Security Updates |
| :--- | :--- |
| `main` (`0.1.x`) | Supported |

## Reporting a Vulnerability

If you discover a security or memory-safety issue (for example in the unsafe Win32/DXGI/OpenXR interop boundary, `.hcvb`/`.hcvp` mmap loader bounds validation, or dependency advisories):

1. **Please do not open a public GitHub issue with exploit details.**
2. Report privately via **GitHub Security Advisories** ("Report a vulnerability" under the Security tab of `RONITERVO/HyperCosmosVR`).
3. Include affected files, reproduction steps or malformed test input, and expected vs. observed behavior.

We aim to acknowledge reports within 72 hours and patch verified memory-safety or binary-parsing issues promptly.
